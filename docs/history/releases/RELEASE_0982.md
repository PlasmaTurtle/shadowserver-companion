# 0.9.82 Dark Matter — Eclipse

> **Historical record.** This document retains its original release or review scope.
> It does not describe current acceptance. See the [current documentation](../../README.md)
> or the [history index](../README.md) before using its instructions or results.

This comparison release changes the application's composition, navigation and reading experience. It preserves the local data model, explicitly requested network operations, source records, dirty-form protection and content-freeze semantics.

## A single visual instrument

A compact icon-and-label rail anchors every view, including Eclipse Observatory. Cyan marks actions, violet marks selection, warm white carries the working record, and pale paper distinguishes documents from controls. Light and dark appearances share the same hierarchy. Reduced-motion preferences disable decorative motion and camera animation.

Workspace is a ranked work index, with real workflow totals, due follow-ups, visible priority rationale and one Observatory entrance. Each investigation appears once. Investigations has its own navigation destination; Packages is a separate view within it. Legacy saved routes continue to work.

Entities open as dossiers: recorded identity, saved contact, observed findings, notification history and a hostname/IP diagram. Its lines mean values co-reported in saved observations, never inferred ownership. Details/edit remains explicit and review flags link there directly. Leads and entity directories use compact editorial rows.

## Investigation studio

The Report view uses a numbered section rail, a large paper canvas and contextual certification. Freeze locks saved content without rendering. Preview and certification render deliberately. Section changes preserve dirty-form safeguards; the appendix output choice stays editable until certification.

Contact & delivery prioritizes current contact values, then saved history. Copy and blank-only Fill remain immediate. Filling reveals the collapsed editor when needed; typed values are retained. Technical provenance is available on demand. Record-activity and saved-plan forms open when requested. Closing has its own focused composition.

## Observatory

Field has semantic detail levels from grouped observations to endpoints and individual source rows. Relationship thickness and recurrence marks encode saved support. Camera focus and zoom keep source context visible; reduced motion applies. Atlas expands overlapping locations. Pulse presents numeric temporal counts. Selection persists across views, with a source ribbon on desktop and an inspector drawer on small screens. Dossiers can open Observatory scoped to an entity.

All links arise from retained source values. Counts describe the loaded observations; unknown geography/dates and view limits remain explicit. Decorative field texture is not additional observed data.

## Reading records

Library defaults to a paper reading view, with editing in a disclosure. Activity is a searchable chronology. Packages separates recipient downloads from the internal evidence record.

New internal packages open with a finding-first evidence dossier: exact grouped observations, saved contacts and attribution, explicit citation links and compact source references. Original rows and raw records remain accessible. Offline search, category navigation, no-JavaScript reading and selected-file hash checks remain available.

New report layout revisions use a neutral color for unavailable severity. Historical layout revisions retain their original rendering; justified paragraphs and established recipient wording remain unchanged.

## Independent installation

The installer identity is `ShadowserverCompanionDarkMatter`, under `%LOCALAPPDATA%`. Its working/demo ports are 8881/8882. Program files, shortcuts, registry keys, mutex, workspace, logs, restore points and saved-credential profile are separate from standard 0.9.8 and Chaos 0.9.81. Export a backup from either earlier app, then import it explicitly in Dark Matter to compare equivalent records. The app does not discover or copy private workspaces automatically.

The source archive extracts under `shadowserver-companion-dark-matter`. No repository upload is part of this release.

## Final sanity corrections

The refreshed build corrects a false busy-port result on immediate restart and
reopens the original evidence detail when the same source link is activated after
Collapse. Evidence navigation preserves normal browser history.

The Windows startup hotfix removes the subsequent client-side port probe after
a home launch showed a loopback timeout being treated as a fatal error. Actual
server binding now determines port availability, and the browser opens only
after this application's server starts. Server failures retain their diagnostic
details in the startup log and surface through the launcher. Existing-session authentication,
workspace locking, data locations and report formats remain unchanged. Install
the refreshed build over Dark Matter and retain existing data.
